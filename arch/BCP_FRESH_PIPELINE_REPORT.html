BCP Fresh Pipeline — Performance Report

pull_bulk_fresh DAG · MSSQL testdb → MinIO → Hive Iceberg · Updated 2026-06-25

Giới thiệu

Báo cáo này ghi lại hiệu năng thực đo của pipeline pull_bulk_fresh — pipeline đồng bộ 22 bảng reference/lookup (không phải CDC, full snapshot mỗi ngày) từ MSSQL vào Hive Iceberg thông qua MinIO, sử dụng BCP làm công cụ extract. Dữ liệu được đo trên môi trường DEV (full data — bảng reference nhỏ, không cần cap 100K rows) và UAT (placeholder, sẽ fill sau).

Khác với pull_bulk (36 bảng CDC, transactional, có thể hàng triệu dòng), pull_bulk_fresh xử lý bảng reference nhỏ — toàn bộ 22 bảng hoàn thành trong ~10 phút trên DEV.

Mục đích: cung cấp baseline thời gian chạy, xác nhận pipeline end-to-end, và là tiền đề để estimate tổng thời gian init load trên UAT/PROD.

BCP (Bulk Copy Program) — Định nghĩa & Cách hoạt động

BCP là command-line utility đi kèm Microsoft SQL Server (mssql-tools). Chức năng: copy dữ liệu giữa SQL Server instance và file — theo hướng queryout (DB → stdout) hoặc in (file → DB).

Cách hoạt động: BCP mở kết nối TDS (Tabular Data Stream — giao thức native của SQL Server) đến database, thực thi query, và stream kết quả ra stdout dưới dạng text thuần (TSV). Không serialize qua JDBC driver, không đi qua JVM.

Resource tiêu thụ:

  • CPU (MSSQL server): query execution + serialize sang TSV text
  • CPU (client pod): grep filter stdout → pyarrow parse TSV → serialize Parquet (CPU-bound)
  • RAM (client pod): buffer pyarrow chunk in-memory (~250 MB/chunk ở 500K rows × avg row size)
  • Network: toàn bộ dữ liệu stream từ MSSQL pod → client pod qua cluster network (TCP/TDS)
  • Storage: không ghi disk local — Parquet chunk ghi thẳng lên MinIO qua boto3 stream upload
